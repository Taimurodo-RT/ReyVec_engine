# ReyVec: правила для работы в репозитории

ReyVec — игровой движок на Rust + Vulkan (векторная графика и реймарчинг SDF), Windows в первую очередь. Владелец: Роман (GitHub `Taimurodo-RT`). Он не программист: технические решения принимаем сами, его спрашиваем только о целях, поведении и внешнем виде. Общение с ним по-русски, простыми словами.

## Источники правды

- План с объяснениями: https://claude.ai/artifact/D68WoaBUm1zQM6v1bBnyQ4
- Статус этапов: `docs/roadmap.md`. Решения: `docs/decisions/`. Установка: `docs/setup-windows.md`.

## Правила

- Одна задача этапа = один PR от `main`. В описании PR заполнять раздел «Как проверить на ПК» по шаблону.
- Перед пушем: `cargo fmt --all`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo test --workspace`, `cargo deny check`.
- `update.bat`, `run.bat` и `scripts/*.ps1` — путь, которым Роман обновляет и запускает локальную версию. Они должны работать всегда. `.ps1` хранить в UTF-8 с BOM (иначе Windows PowerShell 5.1 ломает кириллицу), `.bat` и `.ps1` с концами строк CRLF (см. `.gitattributes`). Комментарии в `.bat` только латиницей.
- Песочница (`apps/sandbox`) — то, что Роман запускает для проверки каждого этапа. Выход нового этапа должен быть виден в ней.
- Весь `unsafe` Vulkan только в `reyvec-gpu`.
- Проверки этапов формулируются как «что Роман видит на экране». Замеры времени кадра: RTX 5080, 1920×1080, бюджет кадра 4 мс, реймарчинг 2 мс (`docs/decisions/0003-performance-targets.md`).
- Новая зависимость: только с лицензией из `deny.toml`.
- Среда разработки Claude — Linux без видеокарты: всё, что требует GPU, проверяется на ПК Романа.
