# Установка на Windows

Эта инструкция ставит всё, что нужно для сборки и запуска ReyVec на твоём ПК. Делается один раз. Каждый шаг заканчивается проверкой: если она не проходит, остановись и пришли разработчику текст из окна.

Команды из шагов вводятся в **PowerShell** (Пуск → набрать «PowerShell» → Enter). После установки каждой программы закрывай PowerShell и открывай заново, чтобы он увидел новую программу.

## 1. Git

Git скачивает код движка с GitHub и обновляет его.

1. Скачай установщик с https://git-scm.com/download/win (64-bit Git for Windows Setup).
2. Установи с настройками по умолчанию.

Проверка: `git --version` печатает строку вида `git version 2.xx.x.windows.x`.

## 2. Visual Studio Build Tools

Rust на Windows использует компоновщик Microsoft, без него сборка не пойдёт.

1. Скачай «Build Tools for Visual Studio» с https://visualstudio.microsoft.com/visual-cpp-build-tools/
2. В установщике отметь набор **«Разработка классических приложений на C++»** (Desktop development with C++). Внутри должны быть отмечены «MSVC … C++ x64/x86 build tools» и «Windows 11 SDK» (или Windows 10 SDK).
3. Нажми «Установить». Это несколько гигабайт, займёт время.

Проверка: в меню Пуск появился пункт «Developer PowerShell for VS».

## 3. Rust

1. Скачай `rustup-init.exe` с https://rustup.rs (кнопка для Windows 64-bit).
2. Запусти, на вопрос ответь `1` (установка по умолчанию).
3. Нужная версия Rust сама скачается при первой сборке: она записана в файле `rust-toolchain.toml`.

Проверка: `cargo --version` печатает строку вида `cargo 1.xx.x`.

## 4. Vulkan SDK

Обязателен. В нём компилятор шейдеров `slangc` (без него движок не соберётся), слои валидации (они ругаются на ошибки движка) и программа `vulkaninfo`.

1. Скачай последний Windows-установщик с https://vulkan.lunarg.com/sdk/home#windows
2. Установи с настройками по умолчанию.

Проверка: `vulkaninfo --summary` печатает список устройств. В разделе `Devices` должны быть обе твои видеокарты: **NVIDIA GeForce RTX 5080** и **AMD Radeon(TM) Graphics**, у каждой `apiVersion` 1.3 или выше. Пришли этот список разработчику один раз: по нему видно версии драйверов.

Вторая проверка: `slangc -v` печатает версию компилятора шейдеров, например `2026.17`.

Если встроенной Radeon в списке нет, это нормально для некоторых настроек BIOS. Проверке на ней это помешает, но работе движка нет.

## 5. Скачать ReyVec

Выбери папку, где будет жить локальная версия. Предлагаю `C:\Users\<твоё имя>\ReyVec`.

```powershell
git clone https://github.com/Taimurodo-RT/ReyVec_engine.git $HOME\ReyVec
```

Проверка: в папке `ReyVec` есть файлы `update.bat` и `run.bat`.

## 6. Собрать и запустить

1. Дважды щёлкни `update.bat`. Он скачает свежий код, соберёт песочницу и положит её в папку `dist`. Первая сборка занимает несколько минут, следующие быстрее.
2. В конце должна быть зелёная строка «Обновление завершено».
3. Дважды щёлкни `run.bat`.

Проверка: открывается окно с тёмно-синим фоном. В центре медленно вращается цветной треугольник, вокруг него бегут 12 разноцветных кругов, слева вращается шахматная доска (каждые 2 секунды у неё меняется размер клеток), справа пульсирует жёлтый круг. В заголовке окна видно название видеокарты, число кадров в секунду и время кадра. Окно закрывается крестиком или клавишей Esc.

### Флаги песочницы

Флаги передаются через PowerShell, открытый в папке ReyVec (Shift + правый щелчок по папке → «Открыть окно PowerShell здесь»):

| Команда | Что делает |
| --- | --- |
| `.\run.bat --list-gpus` | Показать видеокарты и подходят ли они движку |
| `.\run.bat --gpu radeon` | Запустить на встроенной Radeon (можно номер из `--list-gpus`) |
| `.\run.bat --no-vsync` | Без вертикальной синхронизации: показывает предельный FPS |
| `.\run.bat --validation` | Включить проверку Vulkan (нужен Vulkan SDK). В конце должно быть «Ошибок валидации Vulkan: 0» |
| `.\run.bat --no-hot-reload` | Не следить за файлами шейдеров |
| `.\run.bat --seconds 10` | Закрыть окно через 10 секунд |
| `.\run.bat --help` | Все флаги |

Лог каждого запуска пишется в `dist\reyvec.log`. Если что-то пошло не так, пришли этот файл.

### Правка шейдеров на лету

Шейдеры (маленькие программы для видеокарты) лежат в папке `crates\reyvec-gpu\shaders`. Пока песочница открыта, она следит за этой папкой: после сохранения файла картинка меняется сразу, без перезапуска.

Попробовать:

1. Запусти `run.bat`, окно оставь открытым.
2. Открой `crates\reyvec-gpu\shaders\sprite.slang` в Блокноте.
3. Найди строку `return c * input.tint;` и замени её на `return c * input.tint * float4(0.3, 1.0, 0.3, 1.0);`, сохрани. Через секунду все круги и доска станут зеленоватыми.
4. Сделай опечатку: замени `input.tint` на `input.tnt`, сохрани. Картинка останется прежней, по краю окна появится красная рамка, а в начале заголовка окна будет «ОШИБКА ШЕЙДЕРА» и текст ошибки. Подробный текст с номером строки есть в `dist\reyvec.log`.
5. Исправь опечатку и сохрани: рамка и надпись исчезнут.
6. Верни файл как было: `git checkout -- crates\reyvec-gpu\shaders`. Иначе `update.bat` откажется обновляться, потому что в папке есть изменённые файлы.

## Как обновляться дальше

- **Свежая версия из `main`:** дважды щёлкни `update.bat`, потом `run.bat`.
- **Проверить PR до слияния:** в PowerShell в папке ReyVec выполни `.\update.bat -Branch <ветка PR>`. Имя ветки написано в описании PR. Чтобы вернуться, снова запусти `update.bat` без параметров.
- Если `update.bat` пишет, что в папке есть изменённые файлы, значит что-то в папке редактировалось вручную. Скрипт ничего не затирает сам: верни файлы командой `git checkout -- .` или пришли список разработчику.

## Необязательные программы (понадобятся позже)

- **RenderDoc** (https://renderdoc.org): снимок кадра по шагам, если картинка сломана. С этапа 1.
- **Tracy** (https://github.com/wolfpld/tracy/releases): профайлер, показывает, куда уходят миллисекунды кадра. С этапа 2. Нужна версия 0.14.1.
