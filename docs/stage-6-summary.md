# Итог этапа 6: игра на векторной сцене

Дата: 2026-11-04. Этап шёл с PR #71 по #87. Решения: [0012 (звук)](decisions/0012-audio.md), [0013 (скрипты)](decisions/0013-scripts.md), [0014 (интерфейс игры)](decisions/0014-game-ui-and-controls.md), [0015 (управление)](decisions/0015-controls-schemes.md), [0016 (физика)](decisions/0016-physics-rapier-local.md). Разбор этапа и стратегия: [документ](https://claude.ai/artifact/QHdBqVs3htfZAL6EGr2uX1).

## Коротко

На векторной сцене со светом теперь есть игра. Герой бегает, прыгает, цепляется за край, бьёт. Враги заданы скриптами на Luau. Есть частицы на видеокарте, звук, анимация костями, физика Rapier, здоровье, меню и консоль разработчика. Управлять можно клавиатурой, мышью и геймпадом, а клавиши и поведение настраиваются в меню. Все замеры ниже сделал Роман на своём ПК. Узких мест, которые мешают начать следующий этап, нет.

## Что умеет

| Что | Где посмотреть в песочнице |
| --- | --- |
| Герой: разгон, прыжок по длине нажатия, рывок, стена, вис на краю, склоны | Сцена из файла (N), стрелки и пробел |
| Уровень из тайлов, доски, подъёмник | Коридор справа от комнаты, «уступы» за колодцем |
| Боёвка: удар, стоп-кадр, тряска, вспышка, манекены | Ctrl / A / левая кнопка мыши |
| Частицы на видеокарте, 100 000 штук | Пыль и искры в игре, фонтан — V |
| Звук синтезом, музыка | Шаги, удары; музыка — O |
| Анимация костями | Сам герой |
| Скрипты на Luau: жук-враг, монеты | Начало коридора, `scenes/*.lua` |
| Физика: тела, сочленения, мягкие тела | Ящики и мяч в комнате; полигон физики (N, следующий файл) |
| Здоровье, меню паузы, настройка клавиш, мыши и поведения | Esc → «Управление» |
| Консоль разработчика | `~` (Ё), «помощь» |

## Проверка по правилу закрытия этапа

Правило Романа: этап закрывается, когда цели подтверждены замерами на обеих видеокартах, а каждое оставшееся узкое место решено или отложено с планом.

| Цель | Итог | Чем подтверждено |
| --- | --- | --- |
| Нажатие → экран не больше 2 кадров при 60 (33 мс) | ✓ | RTX 5080: нажатие → кадр 16,7–16,9 мс; Radeon 11,6–13,4 мс |
| Частицы 100 000 в пределах 0,5 мс | ✓ | RTX 5080: проход «частицы» 0,062 мс; Radeon 0,008 мс после 6.6б |
| Весь кадр в бюджете 4 мс на RTX 5080 | ✓ | Фонтан 100 000, MSAA 4: вся видеокарта 0,50 мс, 144 кадра; полигон физики 0,29 мс |
| Radeon держит 60 кадров | ✓ | Фонтан крупно, MSAA 2: 77 кадров; ниже 70 кадров не падало |
| Логика укладывается в шаг | ✓ | Шаг логики 0,25 / 0,32 мс; полигон физики (397 тел, 54 сочленения): физика 1,08 мс, вся логика 1,2 мс из 16,7 |
| Всё видно и работает в песочнице | ✓ | 6.1–6.13 Роман проверил 2026-11-04: «всё работает» |

### Что не проверено

- **Геймпад**: у Романа его нет. Код проверен тестами, на живом геймпаде — нет.
- **RTX 3060**: такой карты нет.

### Узкие места

Решены на этапе:
- Рисование 100 000 частиц на Radeon (12,9 мс) — видеокарта сама собирает списки живых частиц (6.6б).
- Повторный захват края при забирании (#84).
- Rapier проверен на полигоне перед тем, как строить на нём дальше (6.13).

Отложены:

| Что | Чем грозит | План |
