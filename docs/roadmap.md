# Дорожная карта ReyVec

Полный план с объяснениями: [План игрового движка](https://claude.ai/artifact/D68WoaBUm1zQM6v1bBnyQ4).
Этот файл хранит статус этапов. Он обновляется в каждом PR, который закрывает этап или его часть.

Все замеры: RTX 5080, 1920×1080. Бюджет всего кадра 4 мс, реймарчинга 2 мс. Цели: 144 кадра на эталонном ПК, 60 кадров на RTX 3060.

## Этап 3: задачи

Итог этапа простыми словами: [stage-3-summary.md](stage-3-summary.md). Устройство слоя: [0009-vector-layer.md](decisions/0009-vector-layer.md). Узкие места: [vector-bottlenecks.md](vector-bottlenecks.md).

- [x] 3.1 Модель фигур (`reyvec-vector`): контуры, заливка с правилами NonZero и EvenOdd, обводка (углы, концы), разбиение на треугольники один раз. Рисование треугольниками одной командой на все фигуры. В песочнице сцена «векторы» (клавиши 1 и 2)
- [x] 3.2а Сглаживание MSAA для всей сцены: выкл, 4× (по умолчанию) или 8×, клавиша M, флаг `--msaa`. Если видеокарта не умеет 8×, берётся 4×. Сводит MSAA сама видеокарта; края «как в редакторах» по клавише G (своё сведение, дороже)
- [x] 3.2б-1 Обводки сглаживаются в шейдере по расстоянию до края (работает и при выключенном MSAA)
- [x] 3.2б-2 + 3.3а Кривые в шейдере через трафарет (Loop–Blinn + stencil-then-cover одним способом): клавиша F переключает способ заливки, Z включает лупу ×8
- [x] 3.3б Перетекающие фигуры (точки смешивает видеокарта), способ заливки для каждой фигуры, решение в 0009: треугольники по умолчанию, трафарет для перетекающих и сильно увеличенных; сцена 3 «перетекание»
- [x] 3.4а Градиенты: линейный, радиальный с фокусом, тянуть/отражать/повторять, своё преобразование; у заливок обоими способами и у обводок
- [x] 3.4б Прозрачность группы фигур (слои, в том числе вложенные) и режимы смешивания: обычное, умножение, экран, сложение
- [x] 3.4в Маски и обрезка: маска слоя по прозрачности (обрезка по силуэту, мягкий край) и по яркости, обычная и обратная
- [x] 3.5 Импорт SVG и файлов Motif
  - [x] 3.5а Импорт SVG через `usvg`, сверка тестовых SVG с `resvg`, сцена 6 «SVG» и флаг `--svg`
  - [x] 3.5б Загрузка перетекающих фигур из файлов Motif `*.reyvec.json`: крейт `reyvec-motif`, сцена 7 «Motif» и флаг `--motif`
  - [x] 3.5в Новые фигуры во время игры без остановки кадра: буферы-копилки фигур, загрузка внутри кадра, сцена 8 «поток»
- [x] 3.6 Текст: `parley` + атлас MSDF, кириллица и латиница, переносы, выравнивание
- [x] 3.7 Плоская камера (сдвиг и приближение), стресс-тест на 10 000 фигур с временем процессора и видеокарты
  - [x] Отсечение фигур и текста за краем экрана (после замеров стресс-теста)
  - [x] Перетекающие фигуры пачками: одна пачка на «этаж» неперекрывающихся копий (узкое место 45)
- [x] 3.7б Нарезка кривых под шаг приближения камеры (уровни детализации, идея Романа): без граней при сильном приближении и без лишних мелких треугольников при отдалении

## Этап 4: задачи

Цель: векторная 2D-сцена с мягкими тенями и свечением, первая демонстрация движка. Кадр до 4 мс на RTX 5080, 60 кадров на встроенной Radeon.

- [x] 4.0 Качество по видеокарте: на встроенной MSAA 2× по умолчанию (на остальных 4×), чтобы освободить место свету (узкие места 9 и 40)
- [x] 4.1 Библиотека 2D-SDF в Slang: круг, прямоугольник, кривая Безье, плавное объединение и вырезание
- [x] 4.2 Поле расстояний экрана: фигуры с отметкой «отбрасывает тень» рисуются в маску, из неё каждый кадр строится поле (jump flooding)
- [x] 4.3 Источники света (точечный, направленный, светящиеся фигуры) и мягкие тени по полю
- [x] 4.4 Свечение (bloom) и тонмаппинг, лёгкий шум против полос (узкое место 53)
- [x] 4.5 Объекты целиком из SDF (капли, слизь, магия) рядом с векторными
- [x] 4.6 Демо-сцена для показа; проверка на встроенной Radeon; отражённый свет в 2D (radiance cascades) отдельным экспериментом
  - [x] Демо-сцена «лаборатория мага» (клавиша H, PR #58): RTX 5080 1,23 мс кадра видеокарты, Radeon 8,1 мс (119 кадров)
  - [x] Опыт со светом каскадами лучей (клавиша C, PR #59): RTX 5080 0,83 мс, Radeon 16,4 мс (54 кадра); по умолчанию остаётся обычный свет
- [x] Итог этапа: цели подтверждены замерами Романа на RTX 5080 и встроенной Radeon, каждое оставшееся узкое место решено или отнесено к этапу или условию ([stage-4-summary.md](stage-4-summary.md))

## Этап 5: задачи

Цель: сцена живёт в файле и в мире `bevy_ecs`, логика и рисование в разных потоках, загрузка в фоне без рывков (решения 0010 и 0011).

- [x] 5.1 Файл сцены в RON (`reyvec-scene`): векторные фигуры в слоях (отметка «отбрасывает тень»), источники света, SDF-объекты; ошибки по-русски со строкой; сцена «из файла» в песочнице (клавиша N, `--scene-file`), правка файла сразу видна в окне. Роман проверил: RTX 5080 1,08 мс кадра видеокарты, Radeon 6,8 мс (141 кадр), правка и ошибка в файле работают
- [x] 5.2 Сцена в `bevy_ecs`: предметы — сущности с местом, поворотом, размером и глубиной; вложенные предметы двигаются с родителем; порядок рисования по глубине, слои с тенью собираются сами; пример «первая комната» на предметах
- [x] 5.3 Логика с фиксированным шагом 60 раз в секунду в своём потоке, рисование сглаживает движение между шагами; движение в файле сцены (вращение, качание, покачивание): лампа-маятник, стрелки часов, парящая сфера. Роман проверил: шаг логики RTX 5080 0,05 мс, Radeon 0,09 мс; кадр видеокарты не изменился (5080 0,73 мс, Radeon 6,78 мс, 142 кадра)
- [x] 5.4 Загрузка в фоне: SVG, Motif, нарезка фигур не дают рывков на графике кадра. Поток «загрузка»: файл сцены, уровни детализации при приближении, проверочная «картина» из ~3900 фигур (клавиша U в сцене N, Shift+U — то же в кадре для сравнения). Роман проверил: картина в фоне RTX 5080 21,8 мс в фоне и 0,41 мс в кадре (Shift+U — 21,3 мс в кадре), Radeon 22,7 мс в фоне и 0,73 мс в кадре (Shift+U — 21,4 мс); уровни детализации 1846 фигур — 7,2–7,4 мс в фоне и 0,15–0,31 мс в кадре; картина добавляет Radeon около 0,33 мс кадра видеокарты (7,2 мс, 134 кадра)
- [x] 5.5 Ресурсы, по частям:
  - [x] 5.5а Рисунки SVG (`pictures`) и фигуры Motif (`morphs`) прямо в файле сцены, пути от файла сцены; файл режется один раз и помнится, пока не изменится. В примере — фото в рамке на полке и перетекающая клякса за окном. Роман проверил: RTX 5080 движок на процессоре 0,13–0,21 мс на 3956 фигур, логика 0,05 мс; Radeon 0,12–0,13 мс, логика 0,10 мс, сцена на видеокарте 2,06 мс (как в 5.4 с картиной), 133 кадра
  - [x] 5.5б Удаление форм, на которые больше ничто не ссылается: сцена после сохранения выбрасывает формы, рисунки и файлы Motif, которых больше не спрашивает; новая картина (U) убирает старую вместе с уровнями детализации. На видеокарте место удалённых становится дырами, и когда дыр больше, чем живых фигур, живые по кусочку за кадр переписываются в новые буферы без дыр. Строка «Фигуры» на панели. Роман проверил после сотен нажатий U: RTX 5080 — 7987 живых и 513 480 удалённых фигур, U в фоне 17,5 мс и 1,02 мс в кадре (после исправления освобождения памяти, было 4,82 мс), дыры переписаны 55 раз; Radeon — U 19,6 мс в фоне и 1,04 мс в кадре, движок на процессоре 0,13 мс, видеокарта 5,24 мс (133 кадра, как в 5.5а), дыр 0 после 37 переписываний
  - [x] 5.5в Отсечение света и объектов за экраном: в кадр идут только источники, чей свет достаёт до экрана, и SDF-объекты на экране (до 16 и 16 ближайших к середине), а в сцене их может быть до 1024. В примере коридор справа с 16 бра и 4 лужами (тащи камеру мышью влево), строка «Свет» на панели. Роман проверил: RTX 5080 в комнате 4 источника из 20 и 3 объекта из 23, видеокарта 0,31 мс, движок 0,15 мс; в коридоре 11 источников и 11 объектов, 1,07 мс; Radeon в коридоре 10 источников и 8 объектов, 6,19 мс (144 кадра)
- [x] Итог этапа: цели подтверждены замерами Романа на RTX 5080 и встроенной Radeon, каждое оставшееся узкое место решено или отнесено к этапу или условию ([stage-5-summary.md](stage-5-summary.md))
