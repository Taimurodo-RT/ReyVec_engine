# 11. Словарь

[← Оглавление](README.md)

Термины, которые встречаются в документации, по алфавиту. В скобках — английское название, если оно встречается в коде или статьях.

| Слово | Что это простыми словами | Где подробнее |
| --- | --- | --- |
| **2.5D-вид** | Плоский уровень, нарисованный объёмно: плиты-фигуры выдавлены в толщину. Игра та же, клавиша F2 | [7](07-3d-i-25d.md) |
| **Атлас** | Одна большая картинка, в которой лежит много маленьких (например, все буквы шрифта) | [3](03-vektornyy-sloy.md) |
| **Барьер** | Команда видеокарте «подожди, пока прошлый проход допишет картинку». Ставит граф кадра | [2](02-videokarta.md) |
| **Буфер** | Кусок памяти видеокарты с данными (точки фигур, список ламп) | [2](02-videokarta.md) |
| **Буфер геометрии** (G-buffer) | Картинка, где в каждом пикселе записано, во что попал луч: глубина, нормаль, материал. Свет считается потом по ней | [7](07-3d-i-25d.md) |
| **Валидация** (validation layers) | Проверка каждой команды Vulkan на ошибки. Цель — ноль ошибок | [2](02-videokarta.md) |
| **Вершинный / пиксельный шейдер** | Программа видеокарты для каждой точки фигуры / для каждого пикселя | [2](02-videokarta.md) |
| **Временная картинка** | Картинка, нужная только внутри кадра (слой, поле, свет). Граф берёт её из пула и переиспользует | [2](02-videokarta.md) |
| **Вычислительный шейдер** (compute) | Программа видеокарты не для рисования, а для расчётов (частицы, поле) | [6](06-igrovye-sistemy.md) |
| **Граф кадра** (render graph) | Список проходов кадра с тем, что каждый читает и пишет; сам расставляет барьеры | [1](01-put-kadra.md), [2](02-videokarta.md) |
| **Дизеринг** | Лёгкий шум, который убирает полосы на плавных переходах цвета | [4](04-svet-2d.md) |
| **Запечённое поле** | Поле расстояний, посчитанное заранее и записанное в картинку, чтобы не считать формулы каждый шаг луча | [7](07-3d-i-25d.md) |
| **Затенение в углах** (AO, ambient occlusion) | Мягкое потемнение в углах и щелях, куда меньше попадает рассеянный свет | [7](07-3d-i-25d.md) |
| **Конвейер** (pipeline) | Собранная настройка видеокарты: какие шейдеры, как смешивать цвет | [2](02-videokarta.md) |
| **Контроллер платформера** | Код, который двигает героя «удобно для игрока», а не по законам физики | [6](06-igrovye-sistemy.md) |
| **Кадр в работе** (frame in flight) | Кадр, который видеокарта ещё рисует, пока процессор готовит следующий. У нас их до двух | [1](01-put-kadra.md) |
| **Крейт** (crate) | Часть движка на Rust, отдельная библиотека со своим `Cargo.toml` | [главная](README.md) |
| **Линейный цвет** | Цвет «как свет в физике»: два фонаря вдвое ярче одного. Движок считает в нём, а на экран переводит в sRGB | [1](01-put-kadra.md) |
| **Маска** | Картинка, которая решает, где что видно (обрезка) или что отбрасывает тень | [3](03-vektornyy-sloy.md), [4](04-svet-2d.md) |
| **Морфинг, перетекание** | Плавное превращение одной формы в другую (круг → звезда) | [3](03-vektornyy-sloy.md) |
| **MSAA** | Сглаживание краёв: несколько точек на пиксель, потом усреднение | [3](03-vektornyy-sloy.md) |
| **MSDF** | Поле расстояний для букв в трёх цветовых каналах: буквы чёткие при любом размере | [3](03-vektornyy-sloy.md) |
| **Нормаль** | Направление «от поверхности наружу»; по нему считается, как свет падает на поверхность | [7](07-3d-i-25d.md) |
| **Отсечение** (culling) | Не рисовать и не считать то, что не попадает в кадр | [3](03-vektornyy-sloy.md), [7](07-3d-i-25d.md) |
| **Поле расстояний** (SDF, signed distance field) | Карта или формула: в каждой точке — расстояние до ближайшего края (внутри — со знаком минус) | [4](04-svet-2d.md), [7](07-3d-i-25d.md) |
| **Поле слоя** | Одно плоское поле расстояний для всего неподвижного в 2.5D-уровне | [7](07-3d-i-25d.md) |
| **Поток** (thread) | Отдельный «работник» процессора, который делает свою часть работы параллельно другим | [1](01-put-kadra.md) |
| **Проход** (pass) | Один этап рисования кадра на видеокарте (свет, сцена, вывод) | [1](01-put-kadra.md) |
| **Реймарчинг** (raymarching) | Луч шагает по полю расстояний, пока не упрётся в поверхность | [7](07-3d-i-25d.md) |
| **Рывок** (hitch) | Кадр заметно дольше обычных — у нас дольше полутора средних | [10](10-skorost.md) |
| **Сетка отсева** | Деление пространства на клетки со списком ближайших предметов, чтобы луч не перебирал все | [7](07-3d-i-25d.md) |
| **Слой** | Группа фигур, нарисованная в свою картинку и наложенная целиком (прозрачность группы, режим смешивания) | [3](03-vektornyy-sloy.md) |
| **Снимок сцены** (snapshot) | Готовый список «что где стоит» после шага логики; его читает поток кадра | [1](01-put-kadra.md) |
| **Сущность** (entity), **ECS** | Предмет мира в `bevy_ecs`: номер, к которому прикреплены данные (место, фигура, свет) | [5](05-scena-i-dannye.md) |
| **Свечение** (bloom) | Ореол вокруг ярких мест | [4](04-svet-2d.md) |
| **Трафарет** (stencil) | Способ заливки фигур с точными кривыми при любом увеличении | [3](03-vektornyy-sloy.md) |
| **Уровень детализации** (LOD) | Та же фигура, нарезанная подробнее или грубее под размер на экране | [3](03-vektornyy-sloy.md) |
| **Хитбокс** | Невидимая область, которая «бьёт» в бою | [6](06-igrovye-sistemy.md) |
| **Шаг логики** | Один такт игры: 60 раз в секунду, 16,7 мс | [1](01-put-kadra.md), [6](06-igrovye-sistemy.md) |
| **Шейдер** | Маленькая программа, которую видеокарта выполняет для каждой точки или пикселя. У нас на языке Slang | [2](02-videokarta.md) |
| **Эталонная картинка** | Сохранённый «правильный» кадр, с которым CI сравнивает новый | [9](09-instrumenty.md) |
| **bindless** | Все текстуры на одной полке с номерами: шейдеру достаточно номера | [2](02-videokarta.md) |
| **CI** | Робот на GitHub, который проверяет каждый PR | [9](09-instrumenty.md) |
| **jump flooding** (JFA) | Быстрый способ построить поле расстояний из маски «прыжками» всё короче | [4](04-svet-2d.md) |
| **lavapipe** | Программная видеокарта (считает на процессоре); на ней CI и Claude проверяют картинку | [9](09-instrumenty.md) |
| **RON** | Текстовый формат файлов сцены, похож на запись данных в Rust | [5](05-scena-i-dannye.md) |
| **sRGB** | Цвет «как видит экран»: в нём записаны цвета в файлах и показывается кадр | [1](01-put-kadra.md) |
| **swapchain** | Очередь картинок окна: пока одна показывается, в другую рисуется | [2](02-videokarta.md) |
| **TAA** | Сглаживание, размазанное по нескольким кадрам. У нас не используется (твоё решение) | [7](07-3d-i-25d.md) |
| **Vulkan** | Язык, на котором программа говорит с видеокартой напрямую | [2](02-videokarta.md) |
