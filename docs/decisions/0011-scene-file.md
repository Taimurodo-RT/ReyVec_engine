# 0011. Файл сцены: формат RON и правка на лету

Дата: 2026-11-01. Статус: принято (этап 5.1). Дальше формат растёт вместе с этапом 5: сущности `bevy_ecs`, вложенность, ссылки на SVG и Motif.

## Что решили

- **Сцена — текстовый файл RON** (`scenes/*.ron`). RON похож на запись данных в Rust: поля по именам, списки, комментарии `//`. Его удобно править руками в блокноте, а `serde` читает его без своего разборщика. JSON остаётся для обмена с Motif (решение о `reyvec-morph`), там файлы пишет программа, а не человек.
- **Крейт `reyvec-scene`** читает и проверяет файл, ничего не зная о видеокарте. Он отдаёт готовые списки: векторные фигуры (`SceneItem`), источники света и SDF-объекты. `reyvec-gpu` переводит их в свои записи для буферов. Пределы видеокарты (16 источников, 16 объектов, 128 частей) совпадают в обоих крейтах, это проверяется при сборке.
- **В начале файла формат и версия**: `format: "reyvec-scene", version: 1`. Когда формат изменится несовместимо, версия вырастет, а старые файлы будут читаться переводом со старой версии.
- **Ошибка в файле не ломает сцену.** Если сохранённый файл не читается, рисуется прошлая сцена, а ошибка по-русски, со строкой и столбцом, видна в заголовке окна и на панели. Лишние и неизвестные поля — тоже ошибка: опечатка в имени поля не должна молча пропадать.
- **Формы нарезаются один раз.** Форма фигуры (вид, размер, контур, толщина обводки) отделена от места, поворота и цвета. `ShapeCache` помнит каждую форму, поэтому сдвиг и перекраска при правке файла не создают новых фигур, а новая форма нарезается один раз и едет на видеокарту внутри кадра (как в 3.5в).
- **Слежка за файлом** (`SceneWatcher`) следит за папкой, а не за самим файлом: многие редакторы сохраняют через новый файл и переименование. Текст читается, когда записи в файл стихли на 120 мс, чтобы не прочитать файл на середине записи.
- **Где песочница берёт файл**: свой через `--scene-file`, иначе `scenes/first-room.ron` в папке проекта (рядом с `dist`). Если файла нет, берётся встроенная копия примера без слежки.

## Слабые места и когда к ним вернёмся

- Формы, которые больше не используются, остаются в библиотеке до выхода из программы (библиотека пока только растёт). При ручной правке это сотни форм за вечер, не страшно. Вернёмся с ресурсами (5.5): удаление форм без ссылок.
- Чтение и нарезка файла идут в потоке кадра. Для маленьких сцен это доли миллисекунды (время пишется в лог). Перенос в фоновый поток — 5.4 (решение 0010).
- Список фигур сцены копируется каждый кадр. Для сотен фигур это микросекунды; в 5.2 сцена станет миром `bevy_ecs`, и кадр будет собираться из него.
- Анимации в файле пока нет: сцена неподвижна. Движение придёт с логикой игры (5.3).
