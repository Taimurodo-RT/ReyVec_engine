# 0017. Объёмные формы данными: дерево, программа, стековая машина (7.2)

Дата: 2026-11-04. Статус: принято.

## Задача

Формы для реймарчинга должны описываться данными, а не кодом шейдера: их будут читать из
файла сцены (7.5), менять на лету и собирать мышкой в будущем редакторе. При этом
видеокарта должна считать их быстро — для каждого шага каждого луча.

## Решение

**Дерево формы** (`reyvec_sdf::Shape3`, `crates/reyvec-sdf/src/shape3d.rs`):

| Узел | Что это | Числа |
| --- | --- | --- |
| `Sphere` | шар | `radius` |
| `Box` | коробка | `size` (полные размеры), `round` (скругление углов) |
| `Capsule` | капсула вдоль Y | `height` (без полусфер), `radius` |
| `Cylinder` | цилиндр вдоль Y | `height`, `radius`, `round` |
| `Torus` | тор в плоскости XZ | `radius` (кольца), `thickness` (трубки) |
| `Plane` | плоскость | `normal`, `offset` |
| `Union` | объединить | `shapes`, `smooth` (ширина плавного перехода, м) |
| `Subtract` | вырезать из `base` формы `cut` | `smooth` |
| `Intersect` | пересечь | `shapes`, `smooth` |
| `Move` | сдвинуть, повернуть, увеличить | `at`, `turn` (градусы вокруг X, Y, Z), `scale` |
| `Paint` | материал для всего внутри | `material` (номер) |

Материал (`Material3`): цвет, свечение (с 7.4), сетка на поверхности.

В файле RON это читается так:

```text
Union(smooth: 0.3, shapes: [
    Paint(material: 1, shape: Move(at: (0, 1, 0), shape: Sphere(radius: 1))),
    Move(at: (2, 0.5, 0), turn: (0, 45, 0), shape: Box(size: (1, 1, 1))),
])
```

**Программа.** `compile` превращает дерево в список слов для стековой машины: примитив
кладёт на стек расстояние и материал, операция снимает два значения и кладёт одно. Все
сдвиги и повороты над примитивом сворачиваются в одну матрицу «мир → форма», так что
видеокарта не обходит дерево и не перемножает матрицы. Примитив — 19 слов, операция — 2.
Глубина стека — 8: глубже вложенную форму `compile` не примет и скажет об этом.

**Один шейдер.** `include/sdf3d.slang` выполняет любую программу. Новая форма или правка
не требуют пересборки шейдера. Если какие-то тяжёлые формы окажутся частыми, их можно
будет собирать в отдельный шейдер (этап 8), не меняя данных.

**Зеркало на процессоре.** `Program::distance` выполняет ту же программу на процессоре
(тот же порядок слов и формулы), а `Shape3::distance` считает прямо по дереву. Тесты
сравнивают оба способа в сотнях точек. Процессору это понадобится для игры: попадание,
расстояние до стены, прилипание к поверхности.

**Сцена в буфере.** `pack_scene` кладёт в один буфер кадра заголовок, список объектов
(начало и длина программы, с 7.6 — границы для отсева), материалы и программы.
