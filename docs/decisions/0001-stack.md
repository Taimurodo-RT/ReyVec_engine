# 0001. Технологический стек

Дата: 2026-10-31. Статус: принято.

## Решение

| Задача | Выбор | Запасной вариант |
| --- | --- | --- |
| Язык | Rust (стабильный, версия в `rust-toolchain.toml`), компилятор MSVC | — |
| Графика | Vulkan 1.3 через `ash`, свой безопасный слой `reyvec-gpu` | `vulkano` |
| Память видеокарты | `gpu-allocator` | `vk-mem` |
| Окно | `winit` + `ash-window` | `sdl3` |
| Математика | `glam` | `nalgebra` |
| Шейдеры | Slang → SPIR-V, перезагрузка на лету | GLSL через `shaderc` |
| Мир игры | `bevy_ecs` как библиотека | `hecs` |
| Векторы | `kurbo` + `lyon`, позже свой GPU-растеризатор | — |
| SVG и текст | `usvg`, `parley`, `skrifa`, атлас MSDF | `cosmic-text` |
| Переводы | Fluent (`fluent`) | — |
| Физика | `rapier2d`/`rapier3d` для предметов, свой контроллер персонажа | `avian` |
| Звук | `kira` | `rodio` |
| Геймпады | `gilrs` | — |
| Скрипты | `mlua` + Luau | Rhai |
| Инструменты | `egui` + `egui-ash-renderer` | `imgui-rs` |
| Данные | `serde` + RON, `notify` | JSON |
| Профилирование | `tracing`, `tracy-client` | `puffin` |

## Почему

- Vulkan напрямую даёт полный контроль над видеокартой, который нужен для реймарчинга и своего векторного рендера. Готовые обёртки (wgpu, Bevy) прячут то, что нам важно менять.
- Весь `unsafe`-код Vulkan живёт только в `reyvec-gpu`. Остальные крейты пользуются его безопасным интерфейсом.
- Vello не подходит напрямую: он привязан к wgpu. Его идеи используем для векторного растеризатора версии 2.

## Следствия

- Слои валидации Vulkan включены в каждой отладочной сборке, ошибок валидации быть не должно.
- Версии зависимостей закреплены в `Cargo.lock`, обновляются отдельными PR.
