# 0004. Технические соглашения

Дата: 2026-10-31. Статус: принято.

| Тема | Решение |
| --- | --- |
| Rust | Стабильный, версия закреплена в `rust-toolchain.toml`, редакция 2024 |
| Координаты | Правая система, Y вверх, камера смотрит по −Z. 1 единица = 1 метр. У 2D-камеры «пикселей на единицу», по умолчанию 100 |
| Глубина | Обратная (reverse-Z), 32 бита float |
| Цвет | Расчёты в линейном цвете, кадр в HDR-буфере 16 бит на канал, вывод в sRGB. Цвета из SVG и редакторов считаются sRGB |
| Время | Логика и физика с фиксированным шагом 60 раз в секунду, картинка с интерполяцией между шагами |
| Синхронизация | VSync включён по умолчанию, режим без ограничения для замеров |
| Видеокарта | По умолчанию дискретная, ключ `--gpu` выбирает другую |
| Масштаб Windows | Учитываем 125%, 150% и т. д. для интерфейса и текста |
| Потоки | Окно в главном потоке, логика через планировщик `bevy_ecs`, команды видеокарте сначала из одного потока |
| Ошибки | Лог в файл рядом с игрой, отчёт о падении, понятное окно при потере видеокарты |
| Ресурсы | Исходники как есть (SVG, TTF, PNG, OGG, glTF, RON), кэш готовых данных движок строит сам |
| Шрифты | Свободные с кириллицей, лицензия OFL (например, Inter, Noto Sans) |
| Зависимости | Проверка лицензий `cargo-deny` в CI |
| Крейты | Префикс `reyvec-`, каждый крейт появляется на том этапе, где нужен |
