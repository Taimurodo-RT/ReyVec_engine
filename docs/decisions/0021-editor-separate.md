# 0021. Редактор отдельно от движка

Дата: 2026-11-21. Просьба Романа: «Можем ли мы как-то отделить редактор? Его обновления, похоже, иногда мешают другому треду, который работает над графической системой».

## Что было

- Весь код редактора (около 10,5 тыс. строк) лежал внутри `reyvec-app`, рядом с окном песочницы, панелью и консолью (`crates/reyvec-app/src/editor`). Правка редактора и правка графики меняли одну и ту же часть движка, и их PR задевали друг друга.
- `update.ps1` собирал песочницу и редактор одной командой: ошибка в редакторе ломала Роману всё обновление, и песочница со свежей графикой тоже не обновлялась.

## Что решили

- **Редактор целиком живёт в `apps/editor`** (`apps/editor/src/editor/`, программа `reyvec-editor`). В `reyvec-app` его больше нет.
- **Связь с движком — через короткий список** `reyvec_app::for_editor` (`crates/reyvec-app/src/for_editor.rs`): разбор событий окна в ввод (`input_of`, `to_screen`), клавиши героя (`Controls`, `Input`, `controls_path`), шрифты (`fonts`), журнал консоли (`take_log`, `GOLD`, `RED`). Плюс общее, что и так открыто: `reyvec_gpu` (рендер окна), `reyvec_scene` (файлы сцен), `reyvec_app::snapshot`, `AppError`, `RunSummary`, логи.
- **Кто что трогает:**
  - работа над графикой и движком не правит `apps/editor`. Если она меняет что-то из `for_editor` или API `reyvec-gpu`/`reyvec-scene`, которым пользуется редактор, она чинит только места вызова в редакторе (чтобы всё собиралось), без переделок самого редактора;
  - работа над редактором не правит внутренности движка. Если редактору что-то нужно от движка, это отдельная небольшая правка: новое имя в `for_editor` (или в `reyvec-gpu`) отдельным PR или отдельным коммитом с понятным названием.
- **Обновление у Романа:** `update.ps1` собирает сначала песочницу (ошибка — стоп, как раньше), потом редактор отдельной командой. Если редактор не собрался, это жёлтое предупреждение: песочница обновлена, а в `dist` остаётся прошлый `reyvec-editor.exe`.
- **Проверка в CI:** задача Windows проверяет движок и песочницу без редактора (`--exclude reyvec-editor`), а редактор — своя задача «Editor (clippy, test)». По её красному или зелёному сразу видно, чья правка что сломала.

## Чего не делали

- **Отдельный репозиторий для редактора** — лишнее: редактор показывает настоящий кадр движка, и при каждой правке API движка пришлось бы синхронизировать два репозитория. Отдельной папки и короткого списка связей хватает.
- **Отдельная библиотека `reyvec-editor-core`** — пока не нужна: редактор — одна программа, его код живёт в ней же.

## Слабое место

Правка API `reyvec-gpu` (например, `WindowRenderer`) по-прежнему может сломать сборку редактора. Это видно сразу в CI (задача редактора), а у Романа редактор просто не обновится, песочница — обновится.
