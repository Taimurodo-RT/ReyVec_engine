# 0022. Интерфейс игры: язык `.rui`

Статус: принято, 2026-11-25. Подробности, сравнение подходов и шаги: [`docs/game-ui.md`](../game-ui.md).

## Что решили

- **Весь интерфейс игры** — главное меню, настройки, инвентарь, экран игры (здоровье, выносливость), плашки над предметами и экраны внутри мира — описывается в файлах `ui/*.rui` на одном языке. Новый крейт `reyvec-ui` без видеокарты: разбор, живые свойства, раскладка, итоговый список фигур.
- **Вид языка — как у SwiftUI** (выбор Романа): `Блок(главное) { содержимое или действие }` и модификаторы `.имя(...)` через точку; `$путь` — связь в обе стороны; стили и темы пишутся теми же модификаторами. Стили по образцу CSS (уточнено 2026-11-26): подключаются в блоке `head` в начале файла, как в HTML; стили по виду блока, по классу (`.class(danger)`) и вложенные («кнопки внутри меню»); переменные `var(имя)` из темы, переопределяемые для части экрана (`.var(accent: …)`); наследование свойств текста. Сила правил — лестница, а не «вес» CSS: умолчание → наследование → вид → класс → вложенный → модификатор у блока, на ступени побеждает записанное позже; `!important` нет.
- **Код и визуальный редактор — два равных способа.** Разбор сохраняет оформление файла (отступы, комментарии), редактор меняет только нужные узлы. Рабочее пространство «Интерфейс» в `apps/editor` — шаг И.5. Экраны пишет Роман; Claude — для тестов и примеров.
- **Привязка к игре:** поля `game.*` из снимка потока логики с номерами версий (пересчёт только изменившегося), `settings.*`, своё `state` экрана; команды движка (`open`, `back`, `quit`, `set`, …) и действия на Luau в потоке логики (решение 0013).
- **Рисование — наш векторный слой**, а не чужая библиотека: новый примитив «блок» (скругления, обводка, тень и свечение формулой расстояния в шейдере), буквы MSDF из `reyvec-text`, фигуры SVG и Motif, картинки через общий список текстур; одна команда на весь интерфейс; проход «интерфейс» после обработки кадра в полном разрешении окна.
- **Раскладка** — flexbox и сетка библиотекой `taffy` (MIT).
- **Экран рисуется в любую цель:** окно, слой поверх игры или картинку для материала `Screen` на поверхности в мире (телефон, как в GTA; терминал; табло). Мышь попадает в такой экран лучом из курсора.
- **Управление:** сначала клавиатура и мышь (фокус Tab и стрелками, Enter, Esc) через действия управления (решения 0014, 0015); геймпад — последним шагом, на те же действия.
- **Языки:** сразу русский и английский; все тексты по ключам `tr("ключ")`, слова — в `lang/ru.ron` и `lang/en.ron`, новый язык — новый файл.
- **egui остаётся** для редактора, панели отладки и консоли; из игры он уходит на шаге И.4.

## Почему не готовое

- Slint: лицензии GPL-3 или бесплатная с обязательной надписью — не из `deny.toml`; рисует своими средствами, наш векторный слой подключить нельзя.
- Браузерные движки (CEF, Coherent Gameface, Ultralight): тяжёлые или платные. Noesis: платный и со своим рисованием. Immediate mode (egui): трудно оформлять и анимировать, процессор работает каждый кадр.

## Отложено

- Освещение плашек над предметами лампами — «возможно, на потом» (ответ Романа). Экраны внутри мира освещаются всегда.
- Красивое оформление первого меню — пока простые цвета; картинки, рамки и шейдерные фоны — шаг И.6.
- Чтение экрана для незрячих не планируется.
