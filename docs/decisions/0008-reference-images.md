# 0008. Снимки кадра и проверка по эталонным картинкам

Дата: 2026-10-31. Статус: принято (этап 2.5).

## Снимки

- **F12 в окне.** Следующий кадр после рисования копируется проходом графа «снимок» в память, доступную процессору. Через 2 кадра, когда видеокарта его закончит, кадр читается и сохраняется в PNG отдельным потоком, чтобы не задерживать кадры. Снимок совпадает с экраном, вместе с панелью. Для этого картинкам окна нужно разрешение на копирование (`TRANSFER_SRC`). Если поверхность его не даёт, F12 пишет в лог, что снимков не будет.
- **`--snapshot файл.png` без окна.** Песочница рисует тот же кадр сцены в картинку sRGB, как у окна, но без панели, и сохраняет его. Момент сцены задаёт `--time`, размер задаёт `--size`.

Все снимки хранятся в sRGB, по 8 бит на канал, и выглядят так же, как на экране.

## Эталоны

Тест `crates/reyvec-app/tests/reference.rs` рисует несколько кадров без окна и сравнивает их с PNG из `crates/reyvec-app/tests/reference`:

- кадр сцены этапа 2 в момент 0 с;
- кадр в момент 2,5 с, с другой текстурой шахматки;
- кадр с рамкой ошибки шейдера;
- векторная сцена этапа 3 в моменты 0 с и 2 с.

Правила сравнения:

- Эталоны сняты на программной видеокарте lavapipe, той же, что в CI. Настоящие видеокарты рисуют края и сглаживание текстур чуть иначе, поэтому тест по эталонам запускается только в CI на lavapipe, а не на ПК.
- Допуск: канал пикселя может отличаться на 8 из 255, а сверх этого может отличаться не больше 0,2% пикселей. Мелкие различия версий драйвера так проходят, а заметные изменения картинки ловятся. Намеренная правка, например подкрашенные спрайты, даёт 11–18% отличий.
- Если тест упал, CI прикладывает к запуску артефакт `reference-failures`. В нём для каждого кадра лежат получившийся кадр (`*-actual.png`) и картинка отличий (`*-diff.png`, отличающиеся пиксели красные).
- Если картинка изменилась намеренно, эталоны снимаются заново командой `REYVEC_UPDATE_REFERENCES=1 cargo test -p reyvec-app --test reference -- --include-ignored`. Новые PNG коммитятся в том же PR, и по ним видно, что изменилось.

Панель egui в эталоны не входит: её текст меняется каждый кадр (FPS, миллисекунды).
