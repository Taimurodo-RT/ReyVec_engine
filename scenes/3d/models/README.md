# Модели для сцен 3D

- `machine.glb` — простой станок для проверки загрузки glTF (задача 8.14). Собран скриптом
  `machine.py` (`python3 machine.py` пишет файл заново). Своя работа, CC0.
- `crate.glb` — деревянный ящик с текстурой цвета (картинка PNG 64×64 внутри файла) для
  проверки текстур (задача 8.14б2). Собран скриптом `crate.py`. Своя работа, CC0.
